流動性・値幅（この戦略が機能するために必要な構造的条件）を中核条件とします。「有望」の最終判断はStage 2（左でバックテストを実行）で行ってください——ここでの絞り込みだけでは有望性は保証されません。

take_profit 10% / stop_loss 5% / 保有上限2営業日という戦略の前提に対し、この期間内に十分値動きしているかを見ます。

値幅（Amplitude）の判定順にソートされます。値幅が大きいほど戦略の値幅目標に届きやすい一方、ギャップリスク（急落・急騰）も大きくなる点に注意してください。
